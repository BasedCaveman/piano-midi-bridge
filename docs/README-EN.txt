PIANO MIDI BRIDGE — quick install

1. Drag "Piano MIDI Bridge" to the Applications folder.
2. Open the app. If macOS blocks it: System Settings → Privacy &
   Security → "Open Anyway". Then allow Bluetooth.
3. Connect the piano to the Mac with a USB cable (USB TO HOST port).
4. On the iPhone, in Smart Pianist: connection icon → Start Connection
   Wizard → Next → Bluetooth → Yes → Yes → Next → Connect Bluetooth
   MIDI Device → "Piano Bridge" → ✓ → Next → choose your piano.

Not showing on the iPhone? Settings → Bluetooth → turn the switch on
(turning it off from Control Center blocks new devices).

Keep the "FILTER CLOCK" and "FILTER SENSING" switches on for a stable
connection. Change the language with PT / EN / ES on the panel.

You can close the panel: the bridge keeps running from the keyboard
icon in the menu bar. To reopen it, launch the app again.
